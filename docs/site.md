# Сайт

## Расположение

Все страницы — в [`../site/`](../site/):

| Файл | Назначение |
|------|------------|
| `index.html` | Главная |
| `about.html` | О проекте |
| `team.html` | Участники |
| `blog.html` | Журнал (блог) |
| `resources.html` | Ресурсы |

## Ресурсы

- **`site/css/`** — таблицы стилей (сейчас стили встроены в HTML; при выносе — подключать отсюда).
- **`site/js/`** — клиентские скрипты.
- **`site/images/`** — локальные изображения.

## Локальный запуск

Откройте `site/index.html` в браузере или поднимите статический сервер с корнем `site/`.

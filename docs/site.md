# Статический сайт практики

## Назначение сайта

Сайт в папке [`site/`](../site/) создан как презентационная витрина проекта **«Семья в фокусе»** в рамках проектной практики. Он предназначен для быстрого знакомства с идеей проекта, направлениями контента, командой, журналом публикаций и внешними ресурсами (в том числе группой ВКонтакте).

Хранение верстки в отдельной папке `site/`, общая таблица стилей и лёгкий скрипт согласованы со структурой учебного репозитория [practice_2026](https://github.com/Godzol/practice_2026/tree/main) (раздел статического сайта).

Сайт **статический**: для его показа не нужны backend, база данных или шаг сборки (Webpack/Vite и т.п.). Страницы — это HTML-файлы; оформление вынесено в [`site/css/style.css`](../site/css/style.css).

## Требования практики, которые закрывает сайт

Согласно типовому заданию практики сайт должен содержать:

- домашнюю страницу с аннотацией проекта;
- страницу или раздел «О проекте»;
- страницу «Участники»;
- раздел «Журнал» с несколькими публикациями;
- страницу «Ресурсы»;
- уникальное оформление и графические/визуальные элементы.

Реализация включает все перечисленные разделы. Дополнительно к минимальной схеме practice_2026 сохранена отдельная страница **`about.html`** как полноценный блок «О проекте». В **`blog.html`** размещено **шесть** записей журнала (требование «не менее трёх» выполняется с запасом).

## Стек

Как и в модельном учебном проекте, выбран простой связка без фреймворков:

- **HTML5**;
- **CSS3** (общий файл [`style.css`](../site/css/style.css));
- **Vanilla JavaScript** — один файл [`main.js`](../site/js/main.js) для автоматической подстановки текущего года в подвале.

Такой стек упрощает проверку: достаточно открыть `index.html` или опубликовать папку `site/` через хостинг, подключённый к GitHub (см. [`deployment.md`](deployment.md)).

## Структура файлов

```text
site/
├── index.html
├── about.html
├── team.html
├── blog.html
├── resources.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── images/
```

Каталог **`images/`** зарезервирован под локальные изображения (иконки, фоновые файлы всё ещё частично задаются через внешние URL в CSS/HTML — при желании их можно перенести сюда и обновить пути).

На каждой странице в `<head>` подключено:

```html
<link rel="stylesheet" href="css/style.css">
```

Перед закрытием `<body>`:

```html
<script src="js/main.js" defer></script>
```

Для блоков hero на разных страницах используются классы модификаторы вида **`site-header--index`**, **`site-header--about`** и т.д.; фоновые изображения заданы в `style.css` (без дублирования больших блоков `<style>` в каждом HTML).

## Страницы сайта

### `index.html`

Главная страница: фиксированная навигация; hero-блок **`site-header--index`** с названием проекта и кнопкой «Узнать о проекте»; секция **«Что мы делаем»** с шестью карточками направлений; подвал с годом (`#footer-year` заполняется из `main.js`), ссылкой на ВКонтакте и контактным email.

### `about.html`

Раздел «О проекте»: **`site-header--about`**, миссия и ценности, список типов контента, три карточки-преимущества с изображениями.

### `team.html`

Страница команды без отдельного hero: после навигации сразу секция с заголовком, вступительным текстом и сеткой из шести карточек участников (ФИО, роль, краткое описание задач).

### `blog.html`

Журнал: **`site-header--blog`**, шесть карточек-постов с изображением, заголовком, текстом и датой.

### `resources.html`

Ресурсы: **`site-header--resources`**, сетка карточек с темами (соцсети, статьи, рецепты, книги, кино, игры); рабочая ссылка на группу ВКонтакте.

## Дизайн

Светлая тема: палитра на CSS-переменных **`--primary`**, **`--accent`**, **`--secondary`**, **`--light`**. Единые стили навигации, карточек, кнопок и подвала; на главной карточки «Что мы делаем» используют фоновые изображения в сочетании с полупрозрачным блоком текста поверх них.

Предусмотрена адаптивная ширина сеток (`repeat(auto-fit, minmax(...))`) и корректный `viewport` в разметке.

## Итог

Статический сайт закрывает визуальную и информационную часть практики по проекту «Семья в фокусе» и по организации файлов приближен к репозиторию [practice_2026](https://github.com/Godzol/practice_2026/tree/main): отдельные **`css/style.css`** и **`js/main.js`**, документация в **`docs/`**, публикация из каталога **`site/`**.

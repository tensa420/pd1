# Развёртывание

## Сайт

Разворачивайте содержимое каталога **`site/`** на любом хостинге статики (GitHub Pages, Netlify, Nginx, S3 и т.п.). Корень веб-сервера должен указывать на `site/`.

## Telegram-бот

После появления кода в `src/telegram-bot/` добавьте сюда шаги: сборка, переменные окружения, процесс (systemd, Docker, облако).

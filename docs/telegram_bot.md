# Telegram-бот (вариативная часть)

## Назначение

Вариативная часть практики по проекту **«Семья в фокусе»** реализована в виде Telegram-бота, который расширяет точки контакта с аудиторией помимо сайта и группы [ВКонтакте](https://vk.com/club233650687).

Бот предоставляет быстрый доступ к контенту проекта: приветственное меню, справка по использованию и выдача идей/подсказок в духе семейных активностей.

## Реализация в репозитории

Исходный код размещён в каталоге:

```text
src/telegram-bot/
```

Фактическая структура может отличаться по названиям файлов, но содержит рабочий код бота, конфигурацию и инструкции запуска.

## Реализованные пользовательские сценарии

### `/start`

Бот отправляет приветственное сообщение с кратким описанием проекта «Семья в фокусе» и предлагает начать взаимодействие.

### `/help`

Бот показывает список доступных команд и краткие подсказки по формату взаимодействия.

### Основной сценарий

- обработка текстовых запросов пользователя;
- выдача релевантного ответа в тематике проекта (идеи семейных активностей, переход к ресурсам проекта);
- отправка ссылки на внешние ресурсы проекта при необходимости.

## Связь с сайтом и внешними сервисами

- публичный сайт раздаётся из `site/`; бот может использовать его URL в ответах пользователю;
- интеграция с VK API не является обязательной: достаточно стабильной работы в Telegram и корректных ссылок на ресурсы проекта.

## Конфигурация

Бот использует токен Telegram и переменные окружения (например, URL сайта и ссылки на сообщество). Типовой пример `.env`:

```env
BOT_TOKEN=replace_with_bot_token
SITE_URL=https://example.com/
VK_GROUP_URL=https://vk.com/club233650687
```

Файл `.env` хранится локально и не коммитится в репозиторий.

## Запуск и проверка

Общий сценарий запуска:

```bash
cd src/telegram-bot
npm install
npm start
```

Локально проверены базовые сценарии: запуск процесса, ответы на стартовую команду и обработка пользовательского ввода.

## Ограничения и размещение

- Telegram накладывает ограничения на длину сообщений; длинные ответы при необходимости разделяются;
- при нестабильном доступе к Telegram API бот рекомендуется запускать на площадке с устойчивым доступом к сети Telegram.

## Результат

Telegram-бот реализован и закрывает требование вариативной части практики. В проекте сформирована связка **«сайт + документация + мессенджер»**, где бот выступает интерактивным интерфейсом для пользователя.

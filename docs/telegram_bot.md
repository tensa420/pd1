# Telegram-бот (вариативная часть)

## Назначение

Вариативная часть практики по проекту **«Семья в фокусе»** планируется в виде Telegram-бота, который расширяет точки контакта с аудиторией помимо сайта и группы [ВКонтакте](https://vk.com/club233650687).

Задача бота — дать пользователю быстрый доступ к идеям и напоминаниям в духе проекта (например: короткая подборка активности на вечер, ссылка на свежую публикацию, приветственное меню с разделами). Точное ТЗ может уточняться методическими указаниями к практике; ниже приведена **рекомендуемая** техническая модель по аналогии с оформлением в [practice_2026](https://github.com/Godzol/practice_2026).

## Текущее состояние репозитория

Исходный код размещается в каталоге:

```text
src/telegram-bot/
```

На момент оформления документации каталог зарезервирован под будущую реализацию. После добавления кода структура может выглядеть так:

```text
src/telegram-bot/
├── package.json
├── package-lock.json
├── .env.example
├── README.md
└── src/
    └── index.js
```

(Допустима и другая платформа — например Python + `python-telegram-bot` — если это согласовано с преподавателем.)

## Поведение бота (план)

### `/start`

Приветственное сообщение с кратким описанием проекта «Семья в фокусе» и подсказкой, как пользоваться ботом.

### `/help`

Сводка команд и ограничений (длина сообщений, блокировка спама при необходимости).

### Сценарий по тексту или кнопкам

- ответ пользователю с ссылкой на сайт или на группу ВКонтакте;
- при наличии backend или статического JSON — выдача случайной идеи из заранее подготовленного списка «семейное занятие на сегодня».

## Связь с сайтом и внешними сервисами

- Публичный сайт раздаётся из `site/`; в сообщениях бота удобно указывать опубликованный URL после деплоя.
- Интеграция с VK API необязательна для минимального зачёта; достаточно стабильного ответа бота на команды и осмысленных ответов пользователю.

## Конфигурация (пример для Node.js)

Пример переменных окружения:

```env
BOT_TOKEN=replace_with_bot_token
SITE_URL=https://example.com/
VK_GROUP_URL=https://vk.com/club233650687
```

Файл `.env` не коммитится в репозиторий и перечисляется в `.gitignore` корня проекта.

## Запуск (план, Node.js)

```bash
cd src/telegram-bot
npm install
npm start
```

Режим **polling** удобен для локальной проверки и учебных серверов без публичного HTTPS для webhook.

## Ограничения и размещение

- Telegram накладывает ограничения на длину сообщений; длинный текст разбивается на части.
- На территории РФ доступ к Telegram API может быть нестабильным; для продакшена иногда используют VPS за пределами блокировок — это следует описать в отчёте, если затрагивалось при практике.

## Результат

После реализации вариативная часть демонстрирует связку **«проект — сайт — мессенджер»** и выполняет требование практики по интерактивному дополнению к статическому сайту. До появления кода в `src/telegram-bot/` данный файл выполняет роль **проектного описания** и чеклиста для доработки.

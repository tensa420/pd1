## Общая информация

Репозиторий содержит материалы проектной практики по проекту **«Семья в фокусе»**: статический сайт, документацию в Markdown и каталог `**src/telegram-bot/`** под вариативную часть (Telegram-бот).

Проект посвящён возрождению семейных традиций, совместному досугу и полезному контенту для семей. В рамках практики подготовлен отдельный сайт-витрина: он описывает идею проекта, раздел «О проекте», участников команд, журнал публикаций и ресурсы, включая сообщество во ВКонтакте.

## Выполненные части

- Создан статический сайт в папке `site/` (включая `about.html`), стили — `site/css/style.css`, сценарий подвала — `site/js/main.js`.
- Подготовлена документация в Markdown в папке `docs/`.
- Разделение структуры под вариативную часть: каталог `src/telegram-bot/` (реализация бота по `[docs/telegram_bot.md](docs/telegram_bot.md)`).
- Сайт предназначен для публикации через **хостинг-агрегатор**, связанный с **GitHub** (автоматический деплой после `git push`, корень публикации — каталог `site/`). Для **Netlify** в корне добавлен `[netlify.toml](netlify.toml)` с `publish = "site"` — иначе платформа по умолчанию публикует корень репозитория без `index.html`. Подробности в `[docs/deployment.md](docs/deployment.md)`.
